# Ethics Quiz

A Python project exploring how philosophical ethics can be translated into an interactive quiz. The long-term goal is to build a web application that helps users understand how their moral reasoning aligns with different ethical theories and how those views evolve over time.

## Current Features

* Presents ethical dilemmas to the user
* Offers multiple possible responses
* Assigns weighted scores to ethical theories
* Calculates and displays the user's top ethical alignments

## Ethical Theories

The quiz currently scores responses according to:

* Consequentialism
* Deontology
* Virtue Ethics
* Care Ethics
* Contractualism

## Project Vision

This project will eventually become a full web application where users can:

* Create an account and personal profile
* Take multiple ethics quizzes over time
* View their complete quiz history
* Track how their ethical views change
* Compare different quiz results
* Receive AI-generated summaries of their moral reasoning and how it has evolved

## Why This Project?

Most online ethics quizzes function like personality tests. This project aims to create a more philosophically rigorous system by distinguishing between ethical theories through carefully designed dilemmas, weighted scoring, optional written explanations, and longitudinal analysis.

The goal is not to tell users which ethical theory is "correct," but to help them better understand how they reason about moral problems.
